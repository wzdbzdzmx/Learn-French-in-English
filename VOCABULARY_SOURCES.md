# Vocabulary sources

The bundled `server/data/french-a1-b2.json` pack is adapted from these open resources:

- **Florine content contributors**, [Florine curriculum](https://github.com/MRG-Hazmatz/florine), commit `d99f8696e037b7f3390f3d21934af42ee94e8397`. Curriculum content is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). We extracted French vocabulary, English meanings, and example sentences, assigned broad A1–B2 levels from the unit labels, and removed repeated French expressions.
- **Language Learning Decks contributors**, [French deck](https://github.com/vbvss199/Language-Learning-decks). The repository is MIT licensed and documents its use of [wordfreq](https://github.com/rspeer/wordfreq) data under CC BY-SA 4.0. We selected entries marked useful for flashcards at A1–B2, added noun articles and gender where supplied, normalized multiple English meanings, and removed repeated expressions.

The adapted bundled vocabulary data is distributed under **CC BY-SA 4.0**. This covers the bundled data, not personal learning records or the application code. The level labels and some examples in the source decks were generated or inferred and may contain mistakes. The CEFR does not define one exhaustive word list for every level. You can edit or archive any word in the app.
